# Glossary

- **Forecast:** probability distribution or expected rate for a predeclared future
  space-time-magnitude volume.
- **Prediction:** deterministic statement; outside CHILE-OEF scope.
- **Hazard:** potential physical earthquake effects; not identical to occurrence.
- **Risk:** consequences combining hazard, exposure, and vulnerability.
- **Mc:** magnitude above which a catalog is adequately complete for a stated
  method, region, time, and source.
- **IAS:** percentile-like score of elevated activity anomaly.
- **As-of:** reconstruction using only records available by a cutoff time.
- **Prospective:** forecast archived before target observations occur.
- **Pseudoprospective:** historical replay isolated from future event data but
  potentially using catalog products created later.
- **Champion/challenger:** promoted operational model and competing shadow model.
